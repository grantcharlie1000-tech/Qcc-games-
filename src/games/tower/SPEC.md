# Tower

A one-action precision stacker: tap, click, or press Space/Enter to stop the sliding slab. Motion alternates along the two horizontal axes of an isometric tower. Only the supported interval survives; the overhanging slice visibly falls. Zero overlap ends the run. An alignment within min(3.2 world units, 8% of the current edge) snaps exactly without shrinking and builds a perfect combo. Each landing earns one point; perfects earn a capped consecutive bonus. Speed rises gradually with height.

Rules research: the parent brief defines the moving-block / crop-overhang loop. Genre reference attempted: https://en.wikipedia.org/wiki/Stack_(video_game) (no usable response here; not claimed as read evidence). The project brief is authoritative; this implementation adds explicit fair tolerance, alternating axes, and transparent combo scoring. Original artwork is drawn as Canvas polygons; no imported game art. The parent owns cover.svg.

Model: axis-aligned world rectangles, analytic triangle-wave movement in units/second, input-time collision, 200ms settle interval, deterministic state. Rendering projects x/z to isometric polygons. No collision is inferred from pixels. Snapshots include all slabs, score/combo, phase, elapsed clock, axis, direction and motion elapsed. Restore validates dimensions, nesting, score and timing before accepting. Pause stops RAF and clock; input is ignored while paused, in text fields or open dialogs. Restart works paused; parent controls pause and persistence.

Presentation: lilac sky, static sun and skyline, softly shaded colored slabs with dark edges, shadow footprint, height marker, generous full-board tap target and explicit Drop block button. Camera follows the upper layers. Falling offcuts and landing ring explain geometry; reduced motion removes the fall/flash, preserving essential sliding motion. Logical 400×470 stage scales below 366px; DPR capped at 2. Parent owns score/best and toolbar. No external runtime requests.

Verification: independent literal interval fixtures for both crop directions and axes, edge miss, narrow tolerance, combo reset, frame rate equivalence at 30/60Hz, speed, settle carry, validated round-trip and invalid snapshots. Chromium route tests perform genuine timed pointer/keyboard/touch drops, lose/restart, pause and storage reload, dialog guarding, phone overflow and screenshot.
