# Skills used

- `.agents/skills/using-superpowers/SKILL.md`, `requesting-code-review/`, `verification-before-completion/`: the user's brief served as the design. Verification ran before completion: unit tests, browser tests and screenshots. An independent reviewer subagent reviewed the change, and its findings are recorded in `TEST_RESULTS.md`.
- `.agents/skills/game-development/SKILL.md` and `game-design/`: the core loop (click → feedback → reward), progression pacing and the reward schedule. The intermittent golden cobs and festivals act as variable rewards, and the milestone upgrades as fixed ones. A clear next objective is always on screen. Balance targets were tested with a greedy bot (`tests/games/corn-clicker/sim.ts`) instead of being assumed.
- `.agents/skills/svg-skill/SKILL.md`: the library cover (`public/game-art/corn-clicker/cover.svg`) is pixel art written as crisp-edged SVG rects, generated from the same sprite grids and checked with `xmllint`. In-game art is pixel sprites (`sprites.ts`) rendered to canvas PNGs at runtime, following the user's request for Cookie Clicker-style pixel art.
- `.agents/skills/animate/SKILL.md`: motion is reserved for feedback and stays cheap. It covers the cob squash (180 ms, `cubic-bezier(.23,1,.32,1)`, interruptible via WAAPI cancel), particles and floating numbers (transform and opacity only, at most 70 nodes) and toasts. Reduced motion (in-game option, arcade setting or OS) removes decorative motion but keeps state changes.
- `.agents/skills/test-driven-development/`: rules were developed against `model.test.ts`, covering bulk prices, stacking, offline, clock, prestige, saves, garden and pests.
