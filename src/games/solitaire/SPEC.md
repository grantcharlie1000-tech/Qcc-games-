# Klondike specification

52 distinct cards, four suits, ranks Ace–King. Seeded Fisher–Yates shuffle using a serialized unsigned 32-bit seed. Seven columns receive one to seven cards, round by round; only their final cards face up. Remaining 24 cards begin in Stock, Waste empty. No deal is claimed solvable.

Variation: draw one, unlimited stock recycles, no shuffle on recycling; the oldest waste card is drawn first after a recycle. Fixed suit foundations ascend Ace to King. A tableau destination requires one lower rank and opposite colour; empty columns accept Kings only. Valid face-up descending alternating sequences move together. An exposed covered card flips automatically. Only the top waste or foundation card moves. Foundation cards may return to the tableau. Win requires all four legitimate 13-card foundations, all 52 unique IDs, and no other cards.

Selection is transient; the deterministic session serializes the seed, every card/pile/face, move and recycle counts, and up to 200 prior states. Undo reverses an entire action, including a reveal or recycle. Restores reject wrong versions, malformed piles, hidden cards above face-up cards, illegal face-up sequences/foundations, duplicate/missing IDs, invalid counters/seeds or invalid history. Restart reconstructs the current seed; New deal chooses and stores a new random seed. No auto-complete or fabricated win.

DOM cards give pointer drag, touch pointer gestures, click source → destination, and native Tab/Enter/Space controls. Empty columns have full-height destination buttons. Touch dragging uses a threshold and pointer capture; hit testing uses client coordinates and elementFromPoint, independent of CSS scale. Drag previews preserve sequences; failed drops leave state intact. Context owns sound, scoring (10 per foundation card), status and persistence. Pause disables inputs and cancels drags; disposal aborts listeners and removes preview/DOM. There is no game animation loop. A short CSS foundation celebration occurs only for a legitimate win and respects both reduced-motion settings.

Original art: emerald felt, navy crosshatched backs and ivory cards, redundant suit glyphs/accessible suit names, gold selection and drop outlines. Cover is original SVG with path-based suits, paper fan and crown; title area y=0..95 has no art. Phone layout uses seven equal flexible columns within the available 366px.
