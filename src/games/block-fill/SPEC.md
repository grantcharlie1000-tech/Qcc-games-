# Block Fill specification

Trace one orthogonal, non-overlapping, continuous path from S through every playable square exactly once. The current head has a pale ring and its visit number; every covered square has a number. Diagonals, jumps, row wrapping and revisits are rejected. Moving to the immediate predecessor deliberately removes the last segment. Completion occurs on the last playable square, with no prescribed finishing endpoint. Walls have a crosshatch pattern. This is a Hamiltonian-path puzzle, not a block-placement or Nonogram puzzle.

The twelve gardens grow from 3×3 / 9 squares to 6×6 / 36 squares. A deterministic LCG chooses endpoint reversals and backbite transformations of an initial serpentine Hamiltonian path. A backbite joins the first endpoint to an interior neighbour and reverses the intervening prefix, preserving exactly one simple path; taking a prefix creates irregular wall layouts while preserving solvability. The construction witness is independently checked for coverage, uniqueness and Manhattan adjacency in tests; an independent search also solves every shipped board from scratch. No external level data or runtime requests.

Hints run a depth-first search with the entire current trail fixed. Connectivity and degree-one pruning reject impossible residual graphs; low-degree-first ordering reduces branching. A search solution marks its next square. Proven failure says the trail cannot finish and identifies a prefix with a verified completion; Undo performs each deliberate recovery step. A bounded search that reaches its limit never claims impossibility: it describes a verified undo route. The construction witness is used only to prove a recovery prefix after undoing, never to suggest an illegal step from a divergent current path.

Mouse, trackpad and touch use captured Pointer Events. Coalesced samples are consumed when available. Every movement segment is sampled at one eighth of a logical cell, preventing fast straight movements from skipping cells; diagonal samples do not invent corners and all samples still pass the same move validator. Tap an adjacent square or focus the board and use arrows. Backspace undoes, H hints, Home resets. No global keyboard interception.

Score is a campaign sum over solved gardens of 100 per square plus an efficiency bonus of base × min(1, (squares − 1) / forward steps), less a tenth of base per hint (bonus floored at 0). Forward steps include retraced squares. The snapshot keeps each garden's best {steps, hints}; replays only improve it. Undo and Reset path preserve the current garden and earned points. Next garden appears only after completion. Parent Restart resets to garden one but keeps best records. All controls reject paused input; pause cancels any captured gesture. The versioned snapshot stores the garden, full path and whether this garden has already awarded its completion score; restoration validates bounds, uniqueness, start and adjacency, rejecting incompatible data. Disposing aborts all listeners and removes the root; there are no timers or animation loops.

Original gameplay artwork uses SVG bevelled garden tiles, a rounded dimensional golden ribbon, visit medallions, a pale head ring and striped walls. SVG coordinates scale as one board; cell hit regions remain above 44 CSS pixels at the largest board on a 390px viewport. Feedback is immediate with no decorative motion, respecting reduced-motion settings. Parent owns the replacement cover illustration.
