# Prior verification failures and resolutions

This record preserves the known pre-audit failures from the build session. It is a reconstruction from the tool outputs in the delegation history, not a claim that original Playwright traces survived every subsequent run. Playwright's output directory was reused during those runs. The final frozen checkpoint is cc08465d3cf015ca842f8de80d9c92e6f77f953e; its final eight-browser-test result and evidence remain separately recorded.

1. Initial dependency setup: `npm ci` failed with ENOENT while creating `/home/agent/.npm/_cacache`, after tarball/cache warnings. Retried with an explicitly writable `/tmp/neon-coil-npm-cache`; installation succeeded without dependency or lockfile changes.
2. Initial arena model suite: 12/13 passed. The boost-floor assertion received `20.09999999999986` instead of 20. The implementation's eligibility comparison used a 0.1 margin, leaving unspendable mass. Changed to a small numeric tolerance; the boost-floor regression now passes.
3. First browser run: the straight trip to the rim exceeded the original 30-second test timeout under the forced software-renderer configuration. Ready/paused worlds were changed to render only on change/resize. The rim test uses real held input with 250 ms frame gaps through the production accumulator rather than rendering 660 frames of straight travel. The final test passes and retains the frame-gap coverage.
4. Multi-touch release assertion initially stayed boosted. Native pointer logging showed CDP `touchEnd` with one supplied point ended the steering finger, leaving the boost finger active. This was a harness error; touchEnd with an empty active-point list correctly releases both. A fresh touch start followed by touchCancel independently verifies cancellation. Final native Chromium multi-touch checks pass.
5. Frame-stall assertion initially counted 20 ticks against a 15-tick cap because the HUD's `data-tick` sample could lag by 100 ms. Replaced stale HUD comparison with exact snapshots through the existing host pagehide save path. The final 8-second-stall bound passes; model tests independently verify 15 catch-up ticks.
6. Resize/high-DPI tests intermittently observed the previous backing dimensions (e.g. width 3840 instead of 5120, or height 1800 instead of 1688). Native ResizeObserver delivery is outside the test's fake clock. The check now waits for the actual layout frame and backing dimensions; all tested sizes/DPI pass.
7. A death-during-catch-up edge case was identified during implementation: remaining accumulator time could exceed the restore validator's allowed fractional step after death. The implementation now clears it when the player dies, with a regression asserting a restorable dead snapshot. An intermediate TypeScript check then rejected a narrowed `phase === 'dead'` comparison (TS2367); checking actual player alive state resolved the type error with the same runtime behavior. Final strict checks and all 288 model/core tests passed.
8. Quick keyboard taps could previously be missed if keyup arrived before the next render frame. Direction is now captured on keydown as well as from held keys. The browser suite includes a quick ArrowDown tap and passes.
9. Playwright's built-in recording route was unavailable because its bundled ffmpeg executable was absent. Normal `playwright install ffmpeg webkit` failed with HTTP403 and body `Domain forbidden`, beginning at https://cdn.playwright.dev/dbazure/download/playwright/builds/ffmpeg/1013/ffmpeg-linux.zip. The installer attempted its normal built-in retry endpoints and then failed. No manual direct-curl or alternate-network bypass was attempted. The installed system ffmpeg encoded a real CDP screencast instead.
10. WebKit launch was explicitly attempted and failed because `/tmp/neon-coil-browsers/webkit-2370/pw_run.sh` is absent. WebKit gameplay has not run. This limitation remains open.
11. The Library transfer-helper resources returned `skill package is not available`. No ZIP bytes were downloaded/executed in this environment; the parent-inspected textual requirements were used. No ZIP HTTP403 response occurred here. Direct PDF/video inspection is not claimed.
12. Forced SwiftShader offline tests running concurrently with the final browser suite recorded 33.4 ms median and 66.7–83.3 ms p95 intervals. These slower timings are retained in `offline/offline-results.json` and explicitly described in TEST_RESULTS.md. The dedicated non-recording default Canvas2D benchmark separately measured 16.7–16.8 ms p95 intervals with 3.8–4.7 ms p95 game-loop CPU work. Those figures do not establish physical hardware/trackpad performance or 60 fps under the forced software path.
