# Last Light: playable journeys

The first play-test exposed a structural problem: the campaign averaged 6.55 main ledges and 1,351 pixels of horizontal travel per chapter. Several continuous clears took under four seconds. Hazard counts and pairwise reachability checks did not establish satisfying levels. Five escapes also required an unexplained lamp, while fourteen chapters hid mandatory lamps on routes described as optional.

This revision keeps the forty-chapter story, current controls, detailed art, score rules and optional memories. It replaces the small obstacle strips with authored journeys through several named encounters. Running, jump height, dash commitment, timing, moving platforms and surface momentum supply the challenge. Quiet approaches and landings let players read each new combination. Districts introduce, develop and combine mechanics; the final district uses their combinations. The introduction stays forgiving while teaching the core controls.

Required people, wheels, lamps and bells sit on the main route. Escape and shelter chapters have no switches. Rescue happens early enough to leave a substantial journey with the companion; a departure bell precedes a meaningful final dock crossing. Optional branches carry memories and may provide skilled alternatives. Named sections and their route connections explain how the space fits together. Length comes from several encounters and decisions, with broad rest points between them.

The persistent objective is derived from actual mission state. It names the next actionable fixture and changes to the named exit when the task is finished. The map defaults to the current section, with section selection and an overview, so a longer level remains legible on a phone. In-world fixture numbers match the checklist. Mechanical confirmations describe what changed and the next task without interrupting movement; conversations and journals remain deliberately paused.

Longer journeys have multiple safe flags. Retrying or resuming returns to the furthest reached flag, including after backtracking. Actions and discoveries survive setbacks. Engine wheels disable linked machinery both in physics and rendering. A layout revision marker migrates earlier preview saves, including removing the now-invalid hidden escape lamp without losing chapter progress.

Verification must distinguish reachability from quality. Actual 120 Hz continuous input replays must complete required missions without teleporting between jumps. Route duration, mandatory travel and shortcut checks expose trivial chapters. Optional memories must have outward and return routes. Scene clearance, phone controls, objective state transitions, flag saves and old-save migration remain regression checks. Representative real browser replays and scene inspection supplement the simulation. The updated isolated preview is published only after the new source and hosted build pass their checks.
