# Scalar values and variable-aware caller

The reviewed scalar value component implements the public Boolean return, exact scalar output storage and ordered nonstack output writes of actual integer `142547CE0` and fixed-point `142547EA0` in the declared default image/locale/ISA boundary. The promoted name is `NativeScalarValues`; its frozen source remains `NativeScalarValuesDraft`. Promotion changes the class name and import/fixture paths only. It does not establish scanner stack/control/register/read equivalence, native CRT startup, numeric wrapper diagnostics or technology numeric dispatch.

Actual format literals are `%i` and `%lli`, with inferred radix. An independent review found the first decimal-only draft wrong for hexadecimal and octal prefixes. The incorrect source, original red comparisons and later correction remain retained. Empty or sign-only integer input can return native EOF, which this helper treats as Boolean success while leaving output unchanged. Fixed conversion uses the native five-byte fraction buffer, leading-zero removal, inferred-radix rescan, qword wrapping and separate negative-zero adjustment. These behaviors are preserved rather than normalized to JavaScript number conversion.

The owner stage passes 54 comparisons: 47 actual native returns and seven exact call-entry boundaries for unresolved runtime paths. Independent review passes 120 original-return comparisons and seven separate original-fault/public-partial checks. The seven faults are not counted as successful native returns. Review reconstructs all observed public bytes from ordered supplied state and raw original stores. Both unconditional verifiers pass under optimized Python, with scoped strict typing. [Owner](../../work/iron-meridian/native-technology-scalars/PORT.md) and [review](../../work/iron-meridian/native-technology-scalars-review/REVIEW.md) retain hashes, complete byte bounds, raw writes, failures and explicit limits.
