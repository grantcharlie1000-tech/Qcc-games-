# Native startup in the web entry

The Iron Meridian entry now imports `native-entry.ts`. The previous fictional entry is preserved byte for byte as `prototype.ts`, SHA-256 `a0352a5385eb2c31f6a8e78bbdc2810d712b5da9df56a922a2fcf46d421b1a7d`. Its model, content and renderer files remain available. They are not used as a substitute for native campaign execution.

The native entry selects an installation folder with browser directory input. It captures relevant File references, creates a dedicated module worker, and sends the explicit base-only source described in [NATIVE_LOADER_IMPLEMENTATION.md](NATIVE_LOADER_IMPLEMENTATION.md). The worker executes the recovered supplied-listing VFS ordering and candidate Lua configuration path, validates the authored raw-world input adapter and transfers the province-ID buffer. Parent selection does not choose active DLC, archives or mods.

`native-map-view.ts` renders a diagnostic palette over exact source province pixels and supports pan, wheel/button/pinch zoom, fit and source-pixel hit testing. The colors are authored and carry no political meaning. It is a browser adaptation, not a recovered native renderer or native world initializer. The scene fills the viewport underneath the floating app controls. Campaign execution remains unavailable.

Replacing content, cancelling an import or disposing the game terminates its worker and aborts pending map preparation. Session IDs reject stale messages. After capture, the directory input is cleared to release unrelated File references. The successful worker retains the Lua session for later typed queries; it releases captured content and transferred world references.

Only the input snapshot identity and map camera enter the normal app save store. File bytes and world arrays are excluded. Reloading requires selecting the folder again; no persistent content store is implemented. Camera restoration applies only to a matching input identity. An earlier prototype save is returned unchanged before successful import, then retained as opaque `legacyPrototypeSave` alongside native view metadata. No prototype campaign is converted into native state.

Seven scoped entry tests pass for save preservation, replacement/stale messages, cancellation during map preparation, same-snapshot camera restoration, invalid replacement folders, failed replacement save retention and invalid saved metadata. Their renderer and worker boundaries are mocked.

Screenshots and both reports are retained under `work/iron-meridian/native-app` and its `production` directory.
