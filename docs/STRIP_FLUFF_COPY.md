# Game copy cleanup

Visible instructions, unsolicited hints and decorative taglines were removed from the game screens. Titles, action buttons, scores, results, control accessibility, game-menu rules and explicitly requested hints remain. No CSS, control styling, Liquid Glass, game simulation or save schema changes.
